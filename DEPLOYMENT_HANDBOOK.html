2. Localhost Setup & Running Locally

Before deploying to cloud servers, run the platform locally:

# 1. Install dependencies
cd API && npm install
cd ../UI && npm install
cd ..

# 2. Start Backend (Runs on http://localhost:5000)
npm run dev:api

# 3. Start Frontend (Runs on http://localhost:8080)
npm run dev:ui

5.3 Render Issues Encountered & Solutions

❌ Issue 1: TS5108 / TS5102 (moduleResolution=node10 & baseUrl removed in TypeScript 5.8)
Cause: Render uses modern TypeScript compiler where legacy compiler flags error out.
Fix: Cleaned API/tsconfig.json to standard modern ES2020 compilation.
❌ Issue 2: TS7016 "Could not find a declaration file for module 'express'"
Cause: NODE_ENV=production causes npm install to omit devDependencies where @types/* resided.
Fix: Moved @types/express, @types/bcryptjs, @types/jsonwebtoken, etc. directly into dependencies in API/package.json.
❌ Issue 3: MongooseServerSelectionError (IP Not Whitelisted)
Cause: Render servers connect from dynamic cloud IPs.
Fix: Added 0.0.0.0/0 in MongoDB Atlas Network Access.

6. Frontend Deployment on Vercel

6.1 Vercel Configuration

  1. Import GitHub repository into Vercel.
  2. In Project Settings, set Root Directory to UI.
  3. In Environment Variables:
    Key: VITE_API_URL
    Value: https://fantasy-cricket-api-ro18.onrender.com/api
    Type: Config (Public)
  4. Trigger Deployment → Status becomes Ready!

6.2 Vercel Issues Encountered & Solutions

❌ Issue 1: "404: NOT_FOUND" on initial deployment
Cause: Vercel was building the monorepo root rather than UI/, and missing Nitro's Vercel build target.
Fix: Set Root Directory to UI and configured "build": "NITRO_PRESET=vercel vite build" in UI/package.json.
❌ Issue 2: "Environment variables with public prefix cannot use visibility: secret"
Cause: VITE_ variables are client-facing and cannot be marked as write-only backend secrets.
Fix: Deleted old secret variable and recreated VITE_API_URL with Config visibility.
